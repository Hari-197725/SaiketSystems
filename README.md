# Project 5: Text File Analyzer

## Description

This project is an enhanced version of the To-Do List Application with persistent storage functionality implemented using File I/O operations.

Unlike the previous version where tasks were stored only in memory, this application stores task information in text files, ensuring that data remains available even after the application is restarted.

## Additional Features

* Persistent task storage
* Automatic file creation and management
* Data retrieval after application restart
* File update synchronization
* Error handling for file operations

## Technologies Used

* BufferedReader
* BufferedWriter
* FileReader
* FileWriter

## Implementation Details

Custom JSON serialization and deserialization techniques were implemented to:

* Convert task objects into text format
* Store task information in files
* Reconstruct task objects when reading data from files

## Learning Outcome

This project provided practical experience in file handling, data persistence, serialization concepts, and advanced Java programming techniques.
